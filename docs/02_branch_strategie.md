# Branch-pro-Task
Die Branch-pro-Task-Strategie ist eine agile Methode, bei der für jeden Vorgang, Bugfix oder Feature ein eigener, kurzlebiger Branch vom Haupt-Branch aus erstellt wird.
Damit sollen Änderungen isoliert werden sowie die Transparenz und Code-Reviews erleichtert werden

### Struktur
Pro Aufgabe/Ticket wird ein eigener Branch erstellt

### Workflow
- Branch erstellen (aus Main)
- Entiwckeln/Testen
- Pull-/Merge-Request erstellen
- Reviews berücksichtigen
- Falls erforderlich Änderungen und/oder Bugfixes durchführen
- Merge komplettieren
- Branch löschen
