# Black Market
Willkommen im offiziellen Repository der Black Market Software GmbH. Nachdem die dunklen Zeiten der ZIP-Archive und E-Mail-Anhänge durch das Eingreifen eines tapferen Software Engineers beendet wurden, dient dieses Repository nun als unbezwingbare Festung für unseren Code

## Projektbeschreibung
Dieses Projekt umfasst die vollständige Restrukturierung und Professionalisierung unserer Software-Artefakte. Wir nutzen moderne Git-Workflows, um die Sicherheit unserer Kundendaten zu gewährleisten und die Effizienz unserer Gilde zu steigern
